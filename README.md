# 입속빌런 증상 체크

인스타 [@ipsok_villain](https://www.instagram.com/ipsok_villain/) 프로필 링크용 페이지입니다.
증상을 고르면 의심해 볼 것 · 집에서 할 일 · 진료과를 안내하고, 해당 주제의 릴스로 연결합니다.

## 새 편을 올렸을 때 (릴스 연결)

1. `index.html` 열기 → 연필 아이콘
2. `Ctrl+F`로 편 번호 검색 (예: `25:['`)
3. 빈 따옴표 `''` 안에 릴스 코드 넣기
   - 릴스 주소 `instagram.com/reel/AbC123xyz/` → `AbC123xyz`
4. Commit changes → 약 30초 뒤 사이트에 반영

`EP` 표에 없는 새 편(#28 이후)은 어느 증상 결과에 붙일지도 정해야 해서 코드 수정이 같이 필요합니다.

## 증상 바로가기 (스토리 링크 스티커용)

주소 끝에 `#증상id`를 붙이면 그 질문부터 열립니다.

`cold` 시려요 · `pain` 아파요 · `gum` 잇몸 · `wisdom` 사랑니 · `food` 음식 낌 · `breath` 입냄새 · `sore` 입안 헐음 · `jaw` 턱 · `look` 이가 변함 · `loose` 흔들림 · `after` 치료 후 · `ortho` 교정
